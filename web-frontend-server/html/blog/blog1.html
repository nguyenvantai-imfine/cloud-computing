1. Giới thiệu bài toán

Trong các đề tài đồ án Điện toán đám mây và hệ thống quản trị trường đại học, Student Management Service luôn là dịch vụ lõi. Khi xây dựng MiniCloud, mục tiêu của nhóm là thiết kế một API kết nối giữa api-gateway-proxy-server (Nginx) và application-backend-server (Flask) đảm bảo:

  • Độ trễ cực thấp (< 30ms) trong mạng nội bộ cloud-net.
  • Định tuyến linh hoạt qua cả /api/student và /student/ trên Nginx Reverse Proxy.
  • Bảo mật xác thực OIDC Bearer Token tích hợp với máy chủ định danh Keycloak tại endpoint /secure.

2. Cấu hình Route /student/ trên Nginx API Gateway

Để người dùng bên ngoài có thể truy cập trực tiếp danh sách sinh viên qua địa chỉ http://localhost/student/, chúng ta cấu hình thêm location block trong nginx.conf của api-gateway-proxy-server:

nginx.conf
location /student/ {
  proxy_pass http://application-backend-server:8081/student;
  proxy_set_header Host $host;
  proxy_set_header X-Real-IP $remote_addr;
}

Hy vọng bài viết này giúp các bạn sinh viên có góc nhìn chuẩn mực hơn khi thiết kế Microservices và API Gateway cho đồ án môn học!
