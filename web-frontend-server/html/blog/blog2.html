Cloud Computing & Microservices Architecture

1. Kiến trúc hệ thống MiniCloud 9 Server

Việc triển khai một hạ tầng đám mây thu nhỏ gồm đầy đủ 9 thành phần (Web Server, Application Server, Database MariaDB, Keycloak Auth, MinIO Object Storage, Bind9 Internal DNS, Prometheus, Grafana và Nginx Reverse Proxy) giúp mô phỏng toàn diện cách vận hành của các nền tảng đám mây thực tế như AWS hay GCP.

2. Triển khai Cân Bằng Tải Round Robin & DNS Nội Bộ

Trong hệ thống MiniCloud, lưu lượng truy cập vào cổng 80 được Nginx phân phối luân phiên (Round Robin) giữa hai máy chủ web-frontend-server1 và web-frontend-server2:

nginx.conf & db.cloud.local
upstream web_backend {
  server web-frontend-server1:80;
  server web-frontend-server2:80;
}

# Zone db.cloud.local trên Bind9 DNS Server:
web-frontend-server IN A 10.10.10.10
app-backend         IN A 10.10.10.20
minio               IN A 10.10.10.30
keycloak            IN A 10.10.10.40

Nhờ kết hợp networking, DNS nội bộ và containerization, toàn bộ hệ thống dễ dàng đóng gói qua docker-compose.yml và triển khai đồng nhất trên AWS EC2!
